## Task 1
### Описание
Программа выполняет сортировку целых чисел, считанных со стандартного ввода, с использованием заданного количества потоков.  
Массив разбивается на примерно равные части, каждая часть сортируется в отдельном потоке функцией `qsort`.  
После завершения всех потоков отсортированные данные выводятся в порядке возрастания.

### Сборка
```bash
make all
```

### Использование
```bash
./task1 <threads_count>
```

### Пример
```bash
echo "5 3 8 1 2 7" | ./task1 3
1 2 3 5 7 8
```

## Task 2
### Описание
Программа демонстрирует механизм обмена данными между двумя процессами с использованием именованных каналов (FIFO).  
С помощью системного вызова `fork()` создаются два процесса:

- **дочерний** — читает данные со стандартного ввода и записывает их в первый именованный канал;
- **родительский** — читает данные из второго именованного канала и выводит их на стандартный вывод.

Таким образом, реализован обмен сообщениями между двумя независимыми программами через именнованные каналы (FIFO)

### Сборка
```bash
make all
```

### Использование
```bash
// Терминал 1
./task2 <fifo_1> <fifo_2>
// Терминал 2
./task2 <fifo_2> <fifo_1>
```

### Пример
```bash
// Терминал 1
echo "Hello from first terminal!" | ./task2 chat.fifo1 chat.fifo2
Hello!
// Терминал 2
echo "Hello!" | ./task2 chat.fifo2 chat.fifo1
Hello from first terminal!
```

## Task 3
### Описание
Программа выполняет сортировку строк файла указанным методом. Строки без видимых символов игнорируются. В программе реализованы 4 метода сортировки:

- **plain** - посимвольное сравнение строк
- **lex** - лексикографическое сравнение строк
- **rplain** - посимвольное сравнение строк с конца
- **rlex** - лексикографическое сравнение строк с конца

### Алгоритм

- **Чтение** -  всё содержимое входного файла извлекается в буфер.

- **Разбиение** - строки в буфере отделяются друг от друга. Указатели на начало строки записываются в массив.

- **Сортировка** - указатели на строки сортируются функцией `qsort` одной из 4 функций сравнения.

- **Вывод** - отсортированные строки записываются в выходной файл.

### Сборка
```bash
make all
```

### Использование
```bash
./task3 <input filename> <output filename> <sorting algorithm> 
```
### Пример
```bash
./task3 in.txt out.txt lex 
```
## Task 4
### Описание
Программа демонстрирует разбор аргументов командной строки с помощью `getopt_long`.  
Аргументы разделяются на три группы:

- **короткие опции** — односимвольные флаги `-m`, `-c`, `-s`, `-t`;
- **длинная опция** `--elbrus=<value>` с обязательным аргументом, принимающая строго определённые значения (`1c+`, `2c+`, `2c3`, `4c`, `8c`, `16c`);
- **не‑опции** — все оставшиеся аргументы, не являющиеся опциями.

Результат разбора выводится в разделённом виде.

### Допустимые опции

| Опция            | Описание                              |
|------------------|---------------------------------------|
| `-m`             | короткая опция (флаг)                 |
| `-c`             | короткая опция (флаг)                 |
| `-s`             | короткая опция (флаг)                 |
| `-t`             | короткая опция (флаг)                 |
| `--elbrus=VALUE`  | длинная опция, VALUE ∈ {`1c+`, `2c+`, `2c3`, `4c`, `8c`, `16c`} |

Короткие опции могут комбинироваться (например, `-mst`).

### Сборка
```bash
make all
```

### Использование
```bash
./task4 <options>
```

### Пример
```bash
./task4 -mc --elbrus=8c file1 file2
Short options: 'm' 'c'
Long options: 'elbrus=8c'
Non options: 'file1' 'file2'
```

## Task 5
### Описание
Программа намеренно пытается открыть несуществующий файл с помощью системного вызова `open`.  
Возникшая ошибка обрабатывается, и информация о ней выводится тремя способами:

- `perror` — стандартная функция, печатающая сообщение, описывающее последнюю ошибку;
- `strerror` — получение текстового описания ошибки по её коду;
- прямая проверка `errno` на конкретное значение `ENOENT`.

Программа завершается с кодом возврата, равным `errno`.

### Сборка
```bash
make all
```

### Использование
```bash
./task5
```

### Пример
```bash
./task5
Can't open file: No such file or directory
sys_errlist: No such file or directory
Errno = ENOENT
```

## Task 9
### Описание
Программа находит в массиве целых чисел **непрерывную возрастающую подпоследовательность** максимальной длины. Если таких несколько, выбирается та, у которой сумма элементов наибольшая.

### Алгоритм

- **Чтение** -  строка разбирается на целые числа с помощью `strtol`, пропуская пробельные символы.

- **Поиск** - за один проход по массиву выделяются все непрерывные возрастающие участки. Для каждого фиксируются длина и сумма.

- **Сравнение** - если очередной участок имеет большую длину, он становится кандидатом. При равной длине выбирается участок с большей суммой.

- **Вывод** - печатаются элементы найденного участка через пробел.

### Сборка
```bash
make all
```

### Использование
```bash
./task9
```

### Пример
```bash
./task9
1 2 3 0 4 5 6 0
0 4 5 6
```

## Task 10
### Описание
Программа выполняет парсинг логических выражений и строит таблицу истинности. Допустимые элементы:

- **VAR** - переменная **A-Z**
- **AND** - логическое **и**
- **OR** - логическое **или**
- **NOT** - логическое **не**
- **(** - открывающаяся скобка
- **)** - закрывающаяся скобка

### Алгоритм

- **Токенизация** - программа разбивает входное выражение на простые элементы.

- **Построение дерева** - из токенов методом рекурсивного спуска строится логическое дерево выражения.

- **Поиск переменных** - все переменные в дереве записываются в массив.

- **Построение таблицы** - перебор всех возможных значений переменных и вычисление значения логического выражения методом подъема по дереву.

### Сборка
```bash
make all
```

### Использование
```bash
./task10
<logical expression>
```
### Пример
```bash
echo "A OR NOT B" | ./task10
A B Result
0 0 1
0 1 0
1 0 1
1 1 1
```
